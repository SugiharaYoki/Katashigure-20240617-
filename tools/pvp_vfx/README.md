# PVP 礼装特效 · 2026-11-16

适用 Minecraft Java 26.3，覆盖 1–39 号礼装，独立命名空间 `pvpfx`。按原技能的成功触发、蓄力、飞行、命中和持续状态播放。

## 预览

在游戏中运行 `/function pvpfx:showcase`，面前六格依次展示 39 种释放效果，每种间隔两秒。只有粒子、声音和自动消失的展示物品，不调用伤害或破坏函数，可在创造模式观看。

单独展示：

```mcfunction
/execute at @s positioned ^ ^ ^6 run function pvpfx:skill/24/cast
/execute at @s positioned ^ ^ ^6 run function pvpfx:skill/39/cast
/function pvpfx:cleanup
```

浏览器打开同目录 `preview.html` 可旋转、缩放查看粒子几何和配色。它是生成坐标预览，不是游戏截图，不展示粒子寿命、音效或物品幻影。

## 维护

- `generate.py` 为几何、配色、音效和动画帧源文件；`generated.json` 列出生成函数。运行 `python3 tools/pvp_vfx/generate.py` 重建函数和交互图谱。不要手改带 generated 注释的函数。
- `hooks.json` 记录原有技能接入点。手写事件、生命周期、预览入口在 `data/pvpfx/function`。
- 粒子使用 `force`，观看范围 160 格，声音范围 96 格；没有按人数降级或低画质开关。短音效只跟随触发/蓄力节点，视觉节奏与状态冷却用于避免重复爆发。
- 一次释放动画 24 tick，物品幻影 20 tick；每个展示实体独立计时，支持多人同时施放。持续效果跟随真实技能实体。对局结束及加载时清理已加载的展示实体；卸载中的实体在重新加载后继续有限生命周期。
- 新视觉逻辑只写 `pfx.*` 记分板、`PvpFx*` 标签、`pvpfx:*` 存储。原伤害、消耗、冷却、模式条件、射程、队伍及地图破坏指令保持原样。
- 03、13、14、15 的专属发放物品新增 `custom_data` 视觉标识。旧背包内的这四类物品不会自动补标，下一局重新发放后生效。
- 隐身没有持续公共光环：12 的离场残影停留原位置；15、28 的提示仅本人；03 光环在隐身时隐藏。攻击/释放的短暂公共反馈仍会显示。
- 原礼装的 PVP/生存模式条件继续有效：24 号真实攻击仍须满足原生存模式条件；预览入口在创造模式可用。

## 验证

运行 `python3 tools/pvp_vfx/verify.py` 检查覆盖、函数引用、JSON/Python、视觉命令边界、生命周期和原战斗指令逐行一致性。

`runtime_tests.py` 为独立服务器生成验证包，拒绝正式目录。已在 Purpur 26.3-2658 副本验证 39 种动画、展示物品、生命周期清理、并发、蓄力阶段、五种钻头尺寸、灯笼宏及箭矢标记：333 项断言通过。39 种释放动画加重锤冲击（共 40 个动画）同时启动，经真实服务器 tick 推进后，动画和物品幻影全部自动清理。24 号原技能的 85 项识别、威力、蓄力和破坏回归也通过。

服务端验证不等于客户端画面验收。实际粒子密度、声音混音与多人观感仍需进服体验；没有宣称以客户端逐招游玩。
