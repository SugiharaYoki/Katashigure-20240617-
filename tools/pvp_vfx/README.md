# PVP 礼装特效 · 2026-11-16 第二版

适用 Minecraft Java 26.3，覆盖 1–39 号礼装。设计重点：短促、分阶段、离开身体的爆发；战斗时保留清晰视野。新视觉不需要新增资源包。

## 视觉与视野规则

- 释放分六次脉冲：第 1、2、4、6、8、10 tick；动画实体在第 12 tick 删除（0.6 秒）。粒子自身寿命另算：细尘缩放 0.18–0.24，参考本地客户端实现最长约 9 tick；少量全亮短轨迹明确设为 4 tick。不会在发射器消失后继续留下数秒的大团余光。
- 每一颗粒子在自己的实际位置选择观众：细尘只发给距该点 4–160 格的玩家，短轨迹只发给 6–160 格。施法者、受击者和旁人都受同样保护；没有共享“当前施法者”标签或最近玩家归属猜测。
- 大型纹理位于地面外沿或 3.5 格以上，斩光和碎片向外运动。地面动画仅使用水平朝向，抬头不会把法阵翻到眼前。39 号弹道仍跟随实际射线朝向，两侧轨迹留出瞄准中轴。
- 删除六件环绕物品、胸甲常驻护罩、误月待机环、罗盘逐 tick 重画、持续羽翼及长期粒子笼。私有提示使用“触发一次，持续期间不重播”的锁存；不公开隐身位置。
- 固定烟幕/陷阱只保留每两秒一闪的低位虚线边界。灯域只在启用、换色、满范围时闪一次；持续增益不再伴随跟身光环。
- 清除旧的高柱喷粒子、39 号逐段爆炸、烟墨大团和 26 号遮屏乱码标题；26 号改为简短 actionbar。药水状态隐藏装饰粒子。致盲、伤害、消耗、冷却、射程、建造和地图破坏等实际机制保持原有指令。

近距离粒子是在发送时避让；已发出的原版粒子不能由数据包逐客户端撤回，因此还用短寿命、低位几何和移动缓冲减少迎面穿入。该实现不承诺高速移动或极端仰俯视下绝对零像素遮挡。

## 预览

游戏中 `/function pvpfx:showcase` 在前方六格依次展示 39 种释放效果，每种间隔两秒。可在创造模式观看，不调用攻击逻辑。

```mcfunction
/execute at @s positioned ^ ^ ^8 run function pvpfx:skill/24/cast
/execute at @s positioned ^ ^ ^8 run function pvpfx:skill/39/cast
/function pvpfx:cleanup
```

打开 `preview.html` 可选择礼装，观看动画阶段、旋转远景、切换第一人称并移动观察点检查近身避让。这是坐标模拟，不是客户端截图；贴图、光照和音效以游戏为准。

## 维护与验证

`generate.py` 生成几何、音效、动画帧和预览，`generated.json` 记录生成文件；重建时会移除已退役的生成函数，保留手写事件文件。不要直接编辑生成函数。

```sh
python3 tools/pvp_vfx/generate.py
python3 tools/pvp_vfx/verify.py
```

`verify.py` 校验 39 技能接入、引用、寿命、近场选择器、禁止遮屏粒子、眼睛高度留白、无环绕实体以及战斗指令保留。`visual_changes.json` 逐条记录旧视觉的修改，只有粒子、文字和药水粒子隐藏开关可以豁免；没有宽泛忽略战斗逻辑。

`runtime_tests.py /绝对路径/测试世界/datapacks` 安装隔离测试包，禁止正式目录。执行 `pvpfx_test:all` 后读取 `storage pvpfx_test:result`。39 释放、全部钻头档位与充能阶段、三色灯域、箭矢识别、12 tick 生命周期和并发清理已有 301 项断言通过；原 24 号另有 85 项识别、蓄力、威力和破坏回归通过。40 个动画经真实 tick 推进后全部清理，模拟旧版遗留的展示物品也已清理。

`packet_probe.py /临时目录/结果.json` 只连接本机隔离端口 20101，使用三个无界面的 26.3 协议测试连接；逐包验证实际粒子接收距离和短轨迹参数。测试服需暂时关闭认证、压缩和必选资源包，并在结束后恢复；正式服务器配置不应修改。它不负责画面渲染，不能代替游戏客户端的视觉验收。 已完成三连接实测：全部释放、特殊发射器、私有提示三个场景全部通过，近场越界为零；私有提示连续调用三次仅本人收到一次。记录见 `validation.json`。

测试服执行 `pvpfx_test:packet_positions` 设置三个观测点；探针输入 `reset 场景名`，再执行 `pvpfx_test:packet_casts`、`pvpfx_test:packet_private` 或 `pvpfx_test:packet_specials`。等三个连接均显示 `scenario complete` 后输入 `report` 保存，最后 `stop` 断开。

新逻辑只写 `pfx.*` 记分板、`PvpFx*` 标签与 `pvpfx:*` 存储。03、13、14、15 的物品标识沿用上一版，旧物品下次发放时带标。24 号实际攻击仍需满足原生存模式条件。
