# 德州扑克

目标版本：原版 Java 1.21.11，无需资源包或服务端插件。

入口已隐藏，不在多功能菜单或赌场接待员中展示；只能通过 `/trigger Poker set 1` 打开大厅。支持四张独立的六人桌：人机对局（1 人＋5 个人机）、多人建房与加入、多人和人机混合对局。买入 2,000 筹码，小盲 5、大盲 10；使用赌场现有浮世币（Perm_PersonFSB），1 FSB 兑换 1 筹码。买入前确认，余额不足不入桌；离桌按剩余筹码兑回。人机使用赌场筹码。

牌桌同屏显示公共牌、自己的底牌、底池、六个座位及筹码、当前行动者和最近动作。常用按钮直接过牌／跟注、最小加注、半池、满池、全下、弃牌；自定义加注输入本轮总下注额。选择金额前展示应跟金额、最小合法总额和可用筹码。

采用标准无限注德州规则：52 张无重复牌，底牌两张，翻牌／转牌／河牌各轮下注，发公共牌前烧牌。庄位与盲注顺时针轮转；单挑时庄家兼小盲、翻前先行动，翻后大盲先行动。比牌从七张牌中取最强五张，支持 A2345 小顺子、公共牌平局、踢脚与同花顺。

全下按照各人的总投入建立主池和边池，弃牌投入仍计入底池但不参与获奖；无人跟注的超额退回。平局均分，余数筹码从庄家左手起依座次分配。短码全下不自动恢复已经行动者的加注权；累计不足额加注达到完整加注幅度时恢复。

只剩一名玩家还有筹码时，不再允许追加无人能跟的加注；玩家只需跟注或弃牌，之后自动发完公共牌。结算页的「赢得」表示分得的底池总额，包含自己投入的部分，不表示净利润。

人机使用已公开的公共牌和自己的底牌评估强度，结合跟注成本、随机性与风格决定行动，不读取对手底牌或尚未公开的牌。等待 2 秒后行动。玩家有 30 秒，超时可过牌则过牌，否则弃牌；断线同样处理，连续超时自动离桌。全下玩家的断线不会取消其比牌资格。对局中离桌在规则允许的行动点处理，不抹掉已经投入的筹码。

房主可以开局、下一手、补齐或移除人机；其他玩家可在手牌之间加入。人类席位不足两人时可补人机。房主离线会移交房主；空桌自动释放。玩家可在手牌之间用浮世币补足至 2,000，人机破产后自动补齐。离线退款进入 UUID 绑定的待领账本，重新上线后自动兑回，不依赖玩家仍在原房间。关闭面板保留座位，可以执行 `/trigger Poker set 2` 重新打开。

运行状态、牌堆、筹码和行动序号写入数据包 storage，`/reload` 不重置手牌。所有操作由独立 trigger 分发，校验席位归属、当前行动者、最新行动序号和金额，过期按钮不能重复下注。其他玩家看不到未公开的底牌。

代码生成源为 `tools/holdem_codegen/`，运行 `python3 tools/generate_holdem.py` 更新函数。服务端仅使用生成的数据包文件。

安装或更新后执行 `/reload`，然后执行 `/trigger Poker set 1` 打开大厅，`/trigger Poker set 2` 返回自己的牌桌。普通玩家无需 OP 权限即可使用这两个命令。界面通过内联 `/dialog show` 生成，不需要注册静态对话框或重新安装资源包。最低支持本仓库目标版本 Java 1.21.11。

在隔离的原版 1.21.11 服务端验证了 2,010 组比牌样本（独立枚举全部五张牌组合计算答案）及 250 组边池、平局余数和下注场景。复现时运行 `python3 tools/validate_holdem.py --output <测试数据包>/data/poker_test/function`，在测试服 `/reload` 后依次运行 `poker_test:reset`、`poker_test:eval_0` 至 `poker_test:eval_40`、`poker_test:engine_0` 至 `poker_test:engine_12`。检查 `#validation_failed pk` 为 0，`poker_test:results failures` 为空。引擎测试会写入临时工作区及 99 号测试桌，应只在隔离测试服运行。

普通非 OP 玩家客户端另外验证了买入与取消、自定义加注、过期按钮、底牌隔离、完整双人对局、多人和人机混合对局、房间隔离、断线全下、房主转移、重载后继续手牌、离线退款跨重载保留和只兑回一次、旧座位复用后的 UUID 校验、补码扣款、账户上限，以及连续超时离桌和资金守恒。
